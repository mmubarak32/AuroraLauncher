# Aurora Launcher
macOS-style Android launcher: glass widgets, big squircle icons, 3D tilt + 3D drawer animation.
## Get the APK (no Android Studio needed)
1. Create a GitHub repo, upload this folder's contents (keep .github folder).
2. Actions tab -> "Build APK" -> run. Download artifact `AuroraLauncher-APK` (app-debug.apk).
3. Install APK, press Home, choose Aurora Launcher -> Always.
## Android Studio
Open folder -> Build > Build APK(s).
